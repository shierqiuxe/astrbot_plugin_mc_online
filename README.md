# Minecraft数据看板（astrbot_plugin_mc_online）

盯着我的世界服务器（一台或好几台都行），隔一会儿问一次「现在谁在线」，把结果按天存下来，
在面板「扩展功能 → Minecraft数据看板」里画成图表，聊天里 `/在线` 还能直接出一张卡片。

## 能看到什么

- **多台服务器**：顶部页签切换，每台一页，互不干扰
- **现在在线**：几个人、上限多少、都在谁
- **今日峰值 / 今天来过几人 / 今天合计玩了多少小时**
- **每小时在线曲线**：今天 0 点到 23 点，平均几个、最多几个
- **时段热力图**：近 30 天，周一～周日 × 0～23 点，哪个格子亮就是那个时段最热闹
- **玩得最久排行**：今天 / 本周，谁肝得多一目了然
- **最近进出流水**：几点几分谁上线、谁下线、这一趟玩了多久
- **聊天卡片**：群里发 `/在线`，回一张深色卡片（服务器名、在线状态、人数、峰值/来过、在线名单）
- **人数曲线**：发 `/在线 曲线`，画近 24 小时的在线人数折线图

## 支持平台

只声明了 **aiocqhttp（OneBot v11）** 和 **qq_official（QQ 官方机器人）** 两个平台，
其它平台在插件列表里不会显示这个插件。

## 装法

面板 → 插件管理 → 安装插件，传 `astrbot_plugin_mc_online` 的 zip（内含同名文件夹）。
装完在侧栏「扩展功能」里就能看见「Minecraft数据看板」。

## 配置

面板 → 插件 → Minecraft数据看板 → 设置：

### 多台服务器（推荐）

`servers` 一项搞定，两种填法任挑：

**填 JSON 数组**（能细配每台的查询端口、RCON 密码）：

```json
[
  {"name": "生存服", "address": "mc.a.com", "game_port": 25565},
  {"name": "空岛服", "address": "mc.b.com", "game_port": 30101,
   "mode": "RCON", "rcon_port": 25575, "rcon_password": "xxx"}
]
```

**一行一台**（简单省事，逗号分隔：名字,地址,端口）：

```
生存服,mc.a.com,25565
空岛服,mc.b.com,30101
```

不填 `name` 就拿地址当名字。下面那些旧的单服字段（`address`/`game_port`…）还能用，
只填它们 = 只盯一台，跟以前一样。

| 项 | 说明 |
| --- | --- |
| `servers` | 服务器列表，上面两种填法；**多台就填这个** |
| `address` | 单服模式的 IP 或域名，**不填就不采样** |
| `game_port` | 游戏端口（服务器列表里那个，不是网页端口；有的面板会单独给一个数字） |
| `mode` | 自动 / 查询协议 / RCON / 服务器列表 |
| `query_port` | 查询协议端口，填 0 = 跟游戏端口一样 |
| `rcon_port` | RCON 端口，默认 25575 |
| `rcon_password` | server.properties 里的 rcon.password |
| `interval` | 采样间隔，默认 60 秒，最小 20 |
| `keep_days` | data 按天存，超过这么多天自动删 |
| `time_zone` | 默认 `UTC+8`，图上的时间和「今天」的分界都按它算 |

### 三种取数方式，挑一种能用的

| 方式 | 要服务器开什么 | 能拿到 |
| --- | --- | --- |
| **查询协议** | `enable-query=true`（server.properties） | 全部在线人名 + 人数 ✅最推荐 |
| **RCON** | `enable-rcon=true` + `rcon.password=xxx` | 全部在线人名 + 人数 ✅同样准 |
| **服务器列表** | 什么都不用开 | 人数 + 一部分名字（服务端可能只给前几条）⚠️兜底 |

`mode` 填「自动」就是按 查询协议 → RCON → 服务器列表 的顺序挨个试，
哪条通就用哪条，`/health` 里的「最近来源」会告诉你是哪条在供数。

> 只开服务器列表也能用：人数曲线、时段热力图都是准的，只有「谁在线」可能不全。

## 实时在线名单

视图第二块就是「现在谁在线」：每个人一个牌子，写着名字和这一趟已经在线多久。
右上角「刷新一下」按下去，插件会立刻问一次服务器再回填，不用等自动采样。

> 名单准不准取决于走的哪条通道：查询协议和 RCON 是全的，
> 服务器列表可能只给一部分名字（那时候「人数」还是准的）。

## 指令

- `/在线` —— 全部服各一行概览（人数 + 今天峰值）
- `/在线 服名` —— 看指定那台的详情（多服时）
- `/在线 排行` —— 今天玩得最久的十个人
- `/在线 热` —— 最热闹的五个时段
- `/在线 帮助`

> 本插件只占 `/在线` 一个指令。曾经还挂过 `/mc`，但那跟常见的
> 「MC 服务器管家」类插件撞名，面板上会显示「有冲突」，于是去掉了。

## 数据存在哪

`data/plugin_data/astrbot_plugin_mc_online/`

```
采样/2026-11-11.jsonl   {"t":时间戳,"c":人数,"m":上限}
流水/2026-11-11.jsonl   {"t":时间戳,"n":"名字","a":"进"/"出","d":时长秒}
```

一行一条，直接文本打开就能看，备份也是拷走目录就行。
采样只在「人数变了」或者「五分钟没存」的时候落一条，文件不会涨得很快。

## 常见问题

**Q：装完视图里全是「—」？**
A：先看 `/api/plugin/astrbot_plugin_mc_online/health`，`地址` 是不是空的。填了地址还得能连上——
AstrBot 所在的机器要能访问服务器的游戏端口（UDP 查询端口 / TCP RCON 端口 / TCP 游戏端口）。

**Q：只显示人数，不显示人名？**
A：说明退到了「服务器列表」那条路。去服务器开 `enable-query=true`，或配好 RCON。

**Q：能在群里播报谁上下线吗？**
A：配置里 `announce` 打开，插件会往「最近跟它说过话」的会话里发。默认关着，免得刷屏。

**Q：服务器关着的时候？**
A：采样失败就跳过，不写脏数据，视图状态灯变红并显示最近一次的错误。
